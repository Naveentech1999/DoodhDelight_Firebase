# Doodh Delight
Mobile-first milk delivery attendance and billing Progressive Web App, using HTML5, Bootstrap 5, CSS, JavaScript, Firebase Authentication and Cloud Firestore.

The current Doodhwala UI, customers, products, delivery attendance and billing functionality are carried over. See [FIREBASE_SETUP.md](FIREBASE_SETUP.md). Firebase cloud sync is disabled until `firebase-config.js` is supplied and Firestore rules are published.
